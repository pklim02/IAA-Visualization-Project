# NC State IAA - Career Services Dashboard

Interactive, automated recruitment and placement dashboard for the Institute for Advanced Analytics (IAA) Career Services team at North Carolina State University.

## Overview
Replaces manual spreadsheet updates with real-time analytics for monitoring student recruitment progress, employer engagement, sourcing channel ROI, and compensation benchmarks.

## Key Features
- **Executive Overview**: Real-time cohort placement rate, recruitment stage progression funnel, and monthly placement velocity.
- **Student Profiles**: 75 student profiles mapped with UnityID avatars, stage progression trackers, and full interview timeline histories.
- **Support Radar**: Algorithmic detection of candidates stalled in early screening rounds, final-round conversion gaps, or requesting coaching.
- **Employer Trends**: Corporate partner engagement leaderboard, interview-to-offer conversion yields, and hiring tier classification.
- **Recruiting Sources**: Channel yield comparison (Institute vs. Alumni vs. LinkedIn vs. Career Fairs) to measure sourcing efficiency.
- **Compensation Analytics**: Base salary, signing bonus, and total first-year compensation distributions, role earnings, and work-mode benchmarks.
- **Live Google Form Integration**: Real-time submission simulator that immediately updates all dashboard metrics, with CSV import and export.

## Quick Start
```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```

The application runs on Vite at `http://localhost:5173/`.
